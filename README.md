# LLM Practice – Gemini API

Learning to build AI applications with Python and Google Gemini.

## Notebooks
- [LLM_practice.ipynb](LLM_practice.ipynb) – Gemini API basics, prompt engineering, structured output
- [embeddings_rag_practice.ipynb](embeddings_rag_practice.ipynb) – Embeddings, vector database, RAG

## What's covered
- Calling the Gemini API securely (Colab Secrets)
- Tokens, temperature, error handling and retries, chat memory
- Prompt engineering: context, format, few-shot, step-by-step, rules, templates
- Structured output with JSON schemas (Pydantic) – extracting lease details into pandas
- Embeddings and semantic search
- Vector database (ChromaDB)
- RAG: chunking with overlap, retrieval, grounded answers with sources, "I don't know" handling
- RAG evaluation with a test set

## Tools
Python, Google Gemini API, pandas, ChromaDB, Pydantic, Google Colab
